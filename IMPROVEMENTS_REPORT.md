## Parser accuracy, before and after (task 8)

The deterministic parser was measured (`backend/.venv/Scripts/python tests/eval/run_eval.py`). "Exact" means every field is correct.

**The number to quote is 91.7% on the held-out set.** The tuning set was used to find and fix parser bugs, so its 99.2% is optimistic.

| Set | Exact before | Exact after | intent | location | date | parameter | language | climate period |
|-----|-------------:|------------:|-------:|---------:|-----:|----------:|---------:|---------------:|
| **Held-out, 24 queries (headline)** | 41.7% | **91.7%** | 100 → 100 | 62.5 → 100 | 100 → 100 | 83.3 → 91.7 | — → 100 | — |
| Tuning set, 120 queries | 79.2% | 99.2% | 99.2 → 100 | 95.0 → 100 | 99.2 → 100 | 86.7 → 99.2 | 99.2 → 100 | 84.6 → 100 |

Per language on the tuning set:

| Language | Exact before | Exact after |
|----------|-------------:|------------:|
| English | 70.0 | 100 |
| Hindi | 85.7 | 100 |
| Hinglish | 89.3 | 96.4 |
| Marathi | 75.0 | 100 |

- **How to read this:** the held-out set was written after tuning and scored once, with no changes afterwards. The tuning set is the one the parser was fixed against, so its scores are optimistic.
- **Raw reports:** `tests/eval/results_{before,after,heldout,heldout_before}.json`.
- **Misses left visible:**
  - "hawa kitni tez" ("how strong is the wind") is read as `strong_wind`; my label is `wind`.
  - My labels are inconsistent for "maximum temperature" between English and Hindi in the held-out set.
  - Marathi "पूर" (flood) is not yet a heavy-rain word.

### See a real test notification

1. Start the backend with the venv active (`cd backend; .\.venv\Scripts\Activate.ps1; uvicorn main:app --port 8000`). `GET http://localhost:8000/api/push/config` must say `"available": true`.
2. Start the frontend (`cd weathergpt-web; npm run dev`) and open `http://localhost:3000` in Chrome or Edge. Push needs `localhost` or HTTPS.
3. **Sign in** with a real Supabase account (top right → Sign in). Demo mode has no account and cannot subscribe.
4. Open **Alerts** and pick a location ("Use my current location", or type a city).
5. In **Push alerts**, tap **Alert me for …** and allow notifications when the browser asks. The place appears in the list under the button.
6. Tap **Send test alert**. Within a few seconds the OS shows "WeatherGPT test alert: TEST: WeatherGPT demo alert, not an official IMD warning", and the panel says "Test alert sent". Clicking the notification opens `/alerts`.
7. A second tap within a minute says "One test per minute". If it says the alert could not be delivered:
   - check that notifications for `localhost` are allowed in the browser and in Windows (Settings → System → Notifications);
   - then tap **Alert me** again.
